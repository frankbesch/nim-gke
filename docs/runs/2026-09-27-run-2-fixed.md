## Defects found by this run

1. **Preflight false FAIL (fixed before the passing attempt).** The first
   attempt at 23:03 failed "no existing cluster" although none existed:
   `gcloud container clusters list --filter` prints a warning to stderr when
   nothing matches, and preflight captured stderr as a cluster name. Fix:
   read stdout only. No resources were created by the failed attempt.
2. **Orphaned model-cache disk.** `cleanup.sh` deleted the PVC, waited 10 s,
   and deleted the cluster. The pod still held the disk, so the CSI driver
   could not delete it before the cluster went away. The new post-delete
   disk check caught it: `pvc-61345709-…` (50 GiB pd-balanced, us-central1-a).
   Fix: `cleanup.sh` now waits for the pods to terminate and for each PV in
   the namespace to be deleted (up to 5 min each) before deleting the
   cluster. The fix is not yet proven by a live run.
3. `cleanup.sh` wrote its resource dumps into the working directory (the
   repo root here); they are now gitignored.
